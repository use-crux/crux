# GitHub Branding

Crux keeps the source logo assets in `assets/` so the README, GitHub organization avatar, and repository social preview all use the same visual system.

## Assets

- `assets/crux-mark.svg` - canonical square mark source.
- `assets/crux-logo.svg` - README/logo wordmark.
- `assets/crux-org-avatar.png` - upload to the `use-crux` GitHub organization avatar.
- `assets/crux-social-preview.svg` - canonical social preview source.
- `assets/crux-social-preview.png` - upload to the `use-crux/crux` repository social preview.

## GitHub Settings

GitHub currently requires these image uploads through the web settings UI.

1. Organization avatar:
   - Open `https://github.com/organizations/use-crux/settings/profile`
   - Upload `assets/crux-org-avatar.png`
2. Repository social preview:
   - Open `https://github.com/use-crux/crux/settings`
   - Scroll to **Social preview**
   - Upload `assets/crux-social-preview.png`

The README logo is committed directly and uses `assets/crux-logo.svg`.
