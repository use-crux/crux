What is known, claimed, and guessed

Market evidence ages quickly and vendor case studies are not neutral. This ledger preserves source type, research date, and caveat so the plan can change without turning old claims into folklore.

Last researched: 2026-07-12Prefer primary sourcesRe-check before external use
Evidence policy: repository state supports claims about Crux; vendor documentation supports capability and pricing claims; vendor case studies support only “vendor-reported” outcomes; research papers establish technical plausibility, not customer demand.

Assumption classification

Statement typeHow this plan treats it
ObservedCurrent repository behavior or dated primary documentation.

Research rule

Re-check before pitching externally

Pricing, product capabilities, migrations, funding, and model support can change monthly. Refresh primary sources before using this plan for a partner, customer, or investor conversation.

Founder action

Add customer truth

After each interview or engagement, append the exact problem language, workaround, cost, commitment, and permission level to a private evidence log. Direct customer behavior should gradually replace vendor case studies as the foundation of this plan.
