# Security

Please do not report security vulnerabilities through public issues, pull requests, or discussions.

## Supported versions

Crux is alpha software. Security fixes target the latest code on `main` and the latest published alpha packages once npm publishing begins.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:

https://github.com/use-crux/crux/security/advisories/new

If that link is unavailable, contact a maintainer privately and include:

- The affected package or runtime surface.
- A minimal reproduction or proof of concept.
- The impact and any known mitigations.

We will acknowledge valid reports as quickly as possible, coordinate a fix, and publish advisory details after affected users have a reasonable path to upgrade.
