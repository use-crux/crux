# Code of Conduct

Crux should be a practical, welcoming project for people building production LLM systems. We expect contributors and maintainers to keep discussions respectful, concrete, and focused on improving the work.

## Expected behavior

- Be kind, direct, and constructive.
- Assume good intent, especially when reviewing early alpha APIs.
- Prefer specific examples, reproduction steps, and tradeoffs over broad criticism.
- Respect different experience levels, tools, companies, and deployment constraints.

## Unacceptable behavior

- Harassment, intimidation, personal attacks, or sustained disruption.
- Demeaning language about a person or group.
- Publishing private information without consent.
- Repeatedly ignoring maintainer direction in issues, discussions, or pull requests.

## Enforcement

Maintainers may edit or delete comments, close issues, restrict participation, or block accounts when behavior makes the project less safe or useful for others.

If you need to report conduct privately and no private project contact is available yet, contact a maintainer you already work with or use GitHub's reporting tools. Security issues should follow [SECURITY.md](./SECURITY.md).
