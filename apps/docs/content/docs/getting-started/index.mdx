## What you'll install

Every Crux project needs `@crux/core` plus exactly one adapter for your SDK of choice:

{/* prettier-ignore-start */}

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">```bash npm install @crux/core zod npm install @crux/ai # Vercel AI SDK (most common) ```</Tab>
  <Tab value="pnpm">```bash pnpm add @crux/core zod pnpm add @crux/ai # Vercel AI SDK (most common) ```</Tab>
  <Tab value="yarn">```bash yarn add @crux/core zod yarn add @crux/ai # Vercel AI SDK (most common) ```</Tab>
  <Tab value="bun">```bash bun add @crux/core zod bun add @crux/ai # Vercel AI SDK (most common) ```</Tab>
</Tabs>
{/* prettier-ignore-end */}

<Callout type="info">
  `@crux/ai` is the Vercel AI SDK adapter. You can also use `@crux/openai`, `@crux/google`, or `@crux/anthropic`
  directly — pick whichever SDK you already have in the project.
</Callout>

## A 30-second taste

If you just want to see a working prompt in isolation:

```ts title="hello.ts"
import { prompt } from '@crux/core'
import { generate } from '@crux/ai'
import { openai } from '@ai-sdk/openai'
import { z } from 'zod'

const greet = prompt({
  id: 'greet',
  input: z.object({ name: z.string() }),
  system: 'You are a friendly assistant.',
  prompt: ({ input }) => `Say hello to ${input.name}`,
})

const result = await generate(greet, {
  model: openai('gpt-4o'),
  input: { name: 'World' },
})

console.log(result.text) // string
```

Set `OPENAI_API_KEY` in your environment and run it. That's a complete Crux program.

For a real walkthrough that wires Crux into your stack, pick a framework above.
