---
title: Signals API
description: Exact public API for typed Signal definitions, publication, filtering, and durable Flow waits.
---

Create Signal definitions from the root package:

```ts
import { signal } from "@use-crux/core";
```

Import the complete Signal type and error surface from the focused subpath:

```ts
import {
  SignalError,
  SignalValidationError,
  type Signal,
  type SignalOccurrence,
} from "@use-crux/core/signal";
```

Static Flow wait types and methods live on the existing Flow surface:

```ts
import { flow, type FlowWaitForSignalOptions } from "@use-crux/core/flow";
```

<Callout type="info">
  `publish()` resolves at acceptance, never consumer completion. The default
  in-memory `node()` Runtime is process-local and cannot activate a durable
  Signal-to-Flow wait.
</Callout>
