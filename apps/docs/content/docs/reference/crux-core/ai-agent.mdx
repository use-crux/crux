### `resolve(prompt, options)`

Resolves a prompt into composed instructions and a wrapped model, for frameworks that manage their own model calls.

| Field                 | Type            | Description                                                                                                                                                         |
| --------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`              | `Prompt`        | The prompt to resolve                                                                                                                                               |
| `options.model`       | `LanguageModel` | AI SDK model instance                                                                                                                                               |
| `options.input`       | `object`        | Input values                                                                                                                                                        |
| `options.tokenBudget` | `number?`       | Token budget for context dropping                                                                                                                                   |
| `options.tools`       | `string[]?`     | Tool names registered with the agent framework. Included in devtools traces alongside prompt/context-level tools. Pass `Object.keys(tools)` from your agent config. |

**Returns:** `ResolveResult`

| Property       | Type            | Description                                                               |
| -------------- | --------------- | ------------------------------------------------------------------------- |
| `instructions` | `string`        | Fully composed system message (contexts + prompt)                         |
| `model`        | `LanguageModel` | Model instance, wrapped with tracing middleware when devtools are enabled |

### Devtools integration

When devtools are enabled, `resolve()` automatically:

- **Emits a resolve trace** with the full prompt composition (system parts, tools, token budget, dropped contexts)
- **Wraps the model** so each internal model call (e.g., multi-step tool use) creates a child trace nested under the resolve trace
- **Captures streaming metrics** (TTFT, tokens/sec) for streamed model calls
- **Propagates observability context** so `generate()` calls inside tool handlers link correctly to the agent step
- **Reports tool invocations** extracted from model responses (tool name, args, call ID)

Pass `tools` to include agent framework tool names in the resolve trace's inspect data — otherwise only prompt/context-level tools are visible.

### Usage with Convex Agent

```ts
import { resolve } from '@crux/core/ai-agent'
import { Agent } from '@crux/convex/agent'

const { instructions, model } = await resolve(chatAgent, {
  model: languageModel,
  input: { mode: 'research' },
  tools: Object.keys(tools),
})

return new Agent(components.agent, {
  languageModel: model,
  instructions,
  tools,
})
```

For Convex Agent, prefer `@crux/convex/agent` over raw `@convex-dev/agent` so tool calls and nested child actions remain observable.

### Usage with Mastra

```ts
import { resolve } from '@crux/core/ai-agent'

const { instructions, model } = await resolve(myPrompt, {
  model: openai('gpt-4o'),
  input: { task: 'analyze' },
})

const agent = new Agent({ name: 'analyzer', instructions, model })
```
