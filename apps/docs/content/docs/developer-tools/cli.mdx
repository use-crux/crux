---
title: CLI & TUI
description: Run Crux locally, inspect projects in the terminal, and automate checks with machine-readable output.
---

The `crux` CLI is the entry point for local development and automation.
`crux dev` also provides an interactive terminal workbench when it runs in a
capable terminal.

```bash
npm install -g @use-crux/local

crux dev
crux index status
crux lint
crux eval --offline
crux editor install vscode
```

Use the CLI when you need a scriptable command or exact JSON output. Use the TUI
when you want a live terminal view of runs, Evals, project health, and local
runtime status. Use browser Devtools for deeper visual inspection.
